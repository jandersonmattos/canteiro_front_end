# Mattos Incorporadora - Frontend Next.js

Projeto inicial em Next.js baseado no sistema Streamlit.

## Instalação

```bash
npm install
```

## Rodar projeto

```bash
npm run dev
```

## Acessos

Login:
http://localhost:3000/login

Projetos:
http://localhost:3000/projects
